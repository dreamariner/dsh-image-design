- 2026-11-19  **「手搭大腿」贴不平的系统性修复：锚点落真面 + 掌法向按解剖重定 + 腕的解剖自由度分判**（issue 005）：用户实机截图圈出跪坐的手浮在大腿上方（悬空 17~24mm），并追问「不应该每个动作都调节，为什么还有这种问题」。定位到三个**共享原语**同时失准（不是某个姿势的参数错）：① 语义锚点解析出的接触点算在**假代理**上（锚点段缺角向剖面，椭圆把接触点算到离轴 9~11cm，真实网格面只有 6.3~8.5cm → 偏外 19~40mm；同一个身体部位，碰撞段早有角向剖面）；② 静息系的**掌法向歪 36~43°**（旧算法取顶点法线均值，而 HM08 掌心是碗形，均值落在碗轴上）→ 意图层的世界掌向与静息系的解剖尺子不一致，每个姿势的掌心都偏 36°，改一个姿势只能补另一个姿势的坑；③ **掌厚用 max 取值**被拇指丘污染（61mm vs 真实支撑脊 21.9mm）。修法全在原语层：锚点段补角向剖面且不收缩（接触点必须落在真面上）、掌法向改由手的解剖结构定（掌面法向必为横截面分解的薄轴 ±，正负号用「手指朝掌心侧卷」定）、掌厚改取掌面侧深度 p90 支撑脊且 along/offset 同属一个触斑；再补三条体段自洽的物理规则：锚定手的指尖方向按**体段表面切向**、锚定手的**前臂与手掌同向**（腕伸直）、腕的区间改成**掌屈/背伸与尺桡偏折分开限**（原来夹总夹角，把合法的背伸 33° 判成超限）。结果：跪坐手-腿间隙 24.3mm 悬空 → −2.4mm（贴住）、坐姿 17.6mm → +2.7mm，8 预设穿插 ≤6.2mm；新增「意图满足」门禁四项（掌/指离腿面 −5~10mm、贴腿的是掌心不是手背、指尖不扎腿、达成掌向 vs 意图掌向 ≤40°）；离线渲染逐姿势目检坐跪的手真实搭在大腿上 ✓（issue 005）
- 2026-11-19  **手部姿势的「拧」与「穿模」系统性修复：手的体积按意图手系定向**（issue 005）：用户实机连续三轮截图指出「手拧成耙子 / 手腕扭曲 / 穿模」，前几轮都是按姿势逐个调掌向与肘位（打地鼠）。本轮定位到真根因并在架构层修：HM08 的手是**一根刚骨**（无手指骨），形状固定而朝向可变，而体积采样此前存的是**绑定姿态的世界偏移** → ① 体外投影按绑定朝向判穿模，掌心朝内时指尖其实戳进大腿却判「体外」（walk 右手指尖入腿 53mm、探针只判 5mm）；② `keepFingersOut` 按**上一子步姿势的活体探针**判指尖穿模 → 腕转 → 探针动 → 判据翻转 → 腕反转，形成 **2 周期震荡**（实测腕关节每子步摆 9°、求解器永不落定，实机观感正是「手腕拧成那样」）。修法：体积采样改存**静息手系局部坐标**、用时按意图手系实时定向（`handVolumeLocal` / `orientedOffsets`），采样点取**支撑点**（26 方向极值顶点，取自整块手部顶点）→ 判据成为(意图, 体段) 的**纯函数**，无「姿势 → 采样 → 目标 → 姿势」反馈环；配套：投影用的手系与实际姿势对齐（按前臂方向预算）、手臂链候选留 1.5cm 安全余量（代理比网格胖）、躯干上胸代理顶点集补锁骨骨（腋下代理薄一圈）、腕屈量具改用指尖探针平均方向（拇指比手指长，原量具虚报 5~10°）。结果：8 个预设**全部落定**、穿插 ≤5mm（原 walk 53.6mm / run 35.3mm / stand 15.7mm）、腕屈 ≤32°、5 个拖动场景穿插 0~4.6mm（原跨中线 17.6mm）；新增两条门禁（腕屈 ≤40°、腕逐子步不震荡）✓（issue 005）
